About the application

Yahoo Mail Bridge is a personal automation project designed to consolidate email messages from a Yahoo Mail account into Gmail.

Imported messages are assigned a dedicated Yahoo label in Gmail, keeping them organized separately from regular Gmail messages.

How it works

✓ Secure Yahoo Mail access through IMAP over TLS

✓ Gmail authorization using Google OAuth 2.0

✓ Email import through the official Gmail API

✓ Preservation of original messages and attachments

✓ Automated execution using GitHub Actions

Personal use

This application is developed for personal use. It is not a public email forwarding service and does not offer accounts to third parties.

The application is not affiliated with Google or Yahoo.

Privacy Policy

Last updated: October 26, 2026

1. Overview

Yahoo Mail Bridge is a personal Python-based application designed to copy email messages from a Yahoo Mail account to a Gmail account authorized by the user.

The application is intended for personal use and is not offered as a public email service.

2. Information Processed

The application processes email messages retrieved from the authorized Yahoo Mail account, including message headers, bodies, and attachments.

It also uses authentication credentials and OAuth tokens required to access the authorized email accounts.

3. Google API Access

Yahoo Mail Bridge uses the Gmail API to import messages and identify the Gmail label designated for Yahoo messages.

The application requests permissions limited to the functions needed for this integration, including gmail.insert and gmail.labels.

4. How Data Is Used

Email data is processed solely to copy messages from Yahoo Mail into the authorized Gmail account.

The application does not sell email data, use it for advertising, or intentionally share it with unrelated third parties.

5. Data Storage and Security

Imported email messages are stored in the user's Gmail account. Original messages remain in the Yahoo Mail account.

During local operation, OAuth credentials and tokens are stored on the user's computer. The planned cloud automation uses GitHub Actions and encrypted repository secrets for authentication credentials.

Connections to Yahoo Mail and Google APIs use encrypted transport protocols.

6. Data Retention

Imported messages remain in Gmail until removed by the account owner. Authentication credentials may be revoked or deleted by the user.

7. User Control

The user can stop the integration, revoke Google account access, delete stored credentials, and remove imported emails at any time.

8. Google API Services User Data Policy

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Contact

For privacy-related questions, contact the developer using the support email listed on the application's Google OAuth consent screen.

10. Changes

This privacy policy may be updated to reflect changes to the application's functionality or data processing.
